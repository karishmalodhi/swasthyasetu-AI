How this AI demo works

  1. A reproducible set of synthetic operational examples is generated in code.
  2. An explainable ensemble (Random Forest when scikit-learn is available, pure-Python fallback otherwise) learns a coordination-load index.
  3. At prediction time the model returns the score, a priority category, a suggested next action, and per-feature contributions.
  4. The model only uses operational signals (contact gaps, missed visits, open tasks, stage duration, prior escalations). It never uses clinical measurements.

The displayed index and category are outputs from an invented synthetic target — not calibrated probabilities or care recommendations. A production system would require authorised data, clinician-defined targets, privacy controls, bias evaluation and prospective validation.
